# 产品使用 / How-to 咨询处理策略

客户问 "怎么用 X 功能" / "能不能做 Y"。

## 关键步骤
1. 识别具体功能点
2. **优先搜 Help Center**：`zendesk_search_articles`
3. 找到匹配文章 → `zendesk_get_article` 取标题、正文和 URL
4. 本地知识库 `saas版知识库/07-product-usage.md` + `11-feature-quick-reference.md`

## 回复原则
- 给具体操作路径（Console 菜单 → 子菜单）
- 附文档链接（文档名：URL，不要 markdown 超链接）
- 一句话能说清的绝不写三段
