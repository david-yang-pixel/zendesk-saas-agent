# General product and account investigation

Answer the active customer question directly. Use official docs or runtime-aligned
source for product behavior. Use current tenant-bound evidence for account state.
Use historical tickets only to find investigation pivots. Keep expected behavior,
current state, impact, root cause, and recovery as separate claims.

Before finishing, ask: "If every proposed claim is true, has the customer's actual
question been answered?" If not, continue investigating or return insufficient.
