# Core Casework Investigation

## Principles
1. **Preserve Customer Intent**: Focus strictly on the customer's specific problem without hallucinating or making unsupported assumptions.
2. **Evidence-Driven**: Query real databases, logs, and Zendesk history before stating facts.
3. **Verify Before Replying**: Only make claims when backed by actual tool outputs.
