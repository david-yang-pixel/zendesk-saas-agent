# Dify SaaS Support Standards

## Guidelines
1. **Language Matching**: Always reply in the exact language used by the user (Simplified Chinese, Traditional Chinese, English, Japanese, etc.).
2. **Tone**: Courteous, professional, concise, and technically accurate.
3. **Escalation**: Explain what was checked and provide clear instructions if user needs human assistance.
